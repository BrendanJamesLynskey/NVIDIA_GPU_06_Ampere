# Ampere — A100, RTX 30, and the Birth of the LLM Era

A deep dive into NVIDIA's Ampere architecture (2020-21): GA100 datacenter die (A100, A40, A6000), GA10x consumer/workstation (RTX 30 series), 3rd-generation tensor cores (TF32, BF16, 2:4 structured sparsity), MIG hardware partitioning, NVLink 3.0 with NVSwitch 2.0, and the practical numbers for fine-tuning and INT4 inference in 2026. Includes an interactive Ampere SKU picker.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_06_Ampere/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
